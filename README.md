# Natanael Mendieta - Portfolio

¡Bienvenido a mi portfolio personal! Este proyecto es una Single Page Application (SPA) construida con React, optimizada para SEO y diseñada con un enfoque en alto rendimiento, animaciones fluidas y diseño responsivo.

## 🚀 Características Principales

- **Diseño Moderno y Elegante**: Interfaz de usuario intuitiva con paletas de colores vibrantes y dark mode.
- **Animaciones Fluidas**: Integración con Framer Motion para transiciones, efectos hover y scroll reveal.
- **Totalmente Responsivo**: Adaptable a cualquier tamaño de pantalla (móvil, tablet, escritorio).
- **Estructura Modular**: Componentes reutilizables y código limpio.

## 🛠️ Tecnologías Utilizadas

- **Frontend**: React.js, HTML5, CSS3 Moderno
- **Herramientas de Construcción**: Vite
- **Animaciones**: Framer Motion
- **Iconografía**: Lucide React

## 💻 Instalación y Ejecución Local

Si deseas correr este proyecto en tu entorno local, sigue estos pasos:

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/natadeveloper20/Nata-Mendieta-Portfolio.git
   ```

2. **Navegar al directorio del proyecto**
   ```bash
   cd Nata-Mendieta-Portfolio
   ```

3. **Instalar las dependencias**
   ```bash
   npm install
   ```

4. **Ejecutar el servidor de desarrollo**
   ```bash
   npm run dev
   ```

5. **Abrir en el navegador**
   Ve a `http://localhost:5173` para ver la aplicación corriendo.
